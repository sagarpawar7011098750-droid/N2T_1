## Project Parts

### Part A — Hack Computer Hardware (`.hdl`)
* **`Memory.hdl`**: Decodes `address[13..14]` to route reads and writes across `RAM16K` (`0`–`16383`), `Screen` (`16384`–`24575`), and `Keyboard` (`24576`).
* **`CPU.hdl`**: Decodes 16-bit A- and C-instructions, controls the `A`, `D`, and `PC` registers, connects the `ALU`, and evaluates jump conditions (`JGT`, `JEQ`, `JLT`, etc.).
* **`Computer.hdl`**: Connects `ROM32K`, `CPU`, and `Memory` into the complete Hack computer.
* **Verification**: Tested in the Nand2Tetris Hardware Simulator using the official Project 5 scripts (`Memory.tst`, `CPU.tst`, `ComputerAdd.tst`, `ComputerMax.tst`, and `ComputerRect.tst`). Built-in sub-chips were used for earlier Project 1–3 components in the Web IDE.

### Part B — Two-Pass Python Assembler (`assembler.py`)
* Strips comments (`//`) and blank lines.
* **Pass 1**: Records all `(LABEL)` pseudo-instructions and their ROM addresses.
* **Pass 2**: Translates A- and C-instructions into 16-bit binary machine code and allocates new variables sequentially starting at `RAM[16]`.
* **Extra Feature (`K mod 3 = 0`)**: Writes all resolved labels (ROM addresses) and variables (RAM addresses) to `symbols.txt`.

### Part C — Interactive Box Program (`Box.asm` & `Box.hack`)
* Polls `@KBD` (`RAM[24576]`) in an infinite loop.
* Sets `color = -1` (black) when any key is held down and `color = 0` (white) when released.
* Uses nested row (`20` rows) and column (`4` words/row) loops starting at screen address `18400`, stepping by `+32` words per row to draw a `64 × 20` pixel rectangle.

## How to Run

### 1. Assemble `Box.asm`
Make sure Python 3 is installed, then run:
```bash
python assembler.py Box.asm
```
This generates `Box.hack` and `symbols.txt` in the same directory.

### 2. Run in the CPU Emulator
1. Open the **Nand2Tetris CPU Emulator** (desktop tool or [Web IDE](https://nand2tetris.github.io/web-ide)).
2. Load **`Box.hack`** into ROM.
3. Set animation to **No animation** (or speed around 75–80% in the Web IDE) and click **Run**.
4. Enable the keyboard input in the emulator and hold down any key to display the black box at Row 63. Release the key to clear it.
